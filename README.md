A very simple webinterface for generating qobuz links in any format you like.

I recommend to use a burner account for this because Qobuz may not like many API requests.
All requests are done client-side.

## Usage
1. Copy and open the `index.html` or navigate to the Github Pages deployment linked at the top right info box.
2. Enter credentials and log in to allow the tool to use the API. No premium account is required.
3. Enter an artist name or ID
4. Set the filters that you want
5. Click search
